# EasyMail Pro

Downloads and release notes for [EasyMail Pro](https://easymailpro.tech), a
fast, private desktop email app for Windows and macOS.

**Download the newest version from the [releases page](https://github.com/mdsolutionsdk/easymailpro-releases/releases/latest)**
or from [easymailpro.tech](https://easymailpro.tech/#download).

| System | File |
| --- | --- |
| Windows 10 or 11, 64-bit | `EasyMailPro-Setup-x64.exe` |
| macOS 11 or later (Apple silicon and Intel) | `EasyMailPro-universal.dmg` |

What changed in each version: [easymailpro.tech/changelog](https://easymailpro.tech/changelog).

Questions or problems: hello@easymailpro.tech.

The releases here are published automatically. The app's source code is not
public.
